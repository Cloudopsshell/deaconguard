Released 2026-10-24. Everything in the release: [changelog](https://github.com/Cloudopsshell/deaconguard/blob/main/CHANGELOG.md#192---2026-10-24). How to upgrade: [Upgrade](../../installation/upgrade.md).

## What's new

- **Helm upgrades with `--reuse-values` work from every earlier release.** The chart fills in any setting an older release lacks from its own defaults, and CI checks the chart against every earlier release.
- The [Upgrade](../../installation/upgrade.md#helm) page uses `--reset-then-reuse-values`, and upgrades an agent release only if you installed one.
- Updated Go modules, web dependencies and GitHub Actions.

## Before you upgrade

Nothing to do.

## Kubernetes (Helm and Kustomize)

- Upgrade as on [Upgrade](../../installation/upgrade.md#helm), with `--reset-then-reuse-values`. From this chart, plain `--reuse-values` works too, from any earlier release.
