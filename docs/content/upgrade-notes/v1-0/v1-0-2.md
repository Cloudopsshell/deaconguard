## What's new

- The Compose and Kustomize files pin the image of their own release.

## Before you upgrade

Nothing to do.

## Kubernetes (Helm and Kustomize)

- If you deployed 1.0.1 with the Kustomize files, you were running image 1.0.0 (the same code). Upgrading fixes it.

## Install script and packages

Nothing to do.

## Docker Compose

- If you deployed 1.0.1 with the Compose file, you were running image 1.0.0 (the same code). Upgrading fixes it.
