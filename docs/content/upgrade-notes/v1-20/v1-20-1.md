Released 2026-10-31. Everything in the release: [changelog](https://github.com/Cloudopsshell/deaconguard/blob/main/CHANGELOG.md#1201---2026-10-31). How to upgrade: [Upgrade](../../installation/upgrade.md).

## What's new

- **Cluster images come from the node agents first:** where a node agent already read a build from a running container, a cluster scan takes it from that scan instead of downloading it from its registry. With the node agent on every node, nothing is downloaded. See [Running images](../../usage/kubernetes.md#running-images).
- `server.clusterImageRegistry: false` turns registry reads off completely.

## Before you upgrade

Nothing to do. Only the server changes; any node agent from 1.8.0 on reports what it needs.

## Kubernetes (Helm and Kustomize)

- Upgrade as on [Upgrade](../../installation/upgrade.md#helm).
- To get the most from it, run the [node agent](../../installation/kubernetes.md#3-the-agents) with the **Running containers** check on a schedule, at least daily.
- To stop the server reaching registries for cluster images, add `--set server.clusterImageRegistry=false`.

## Install script and packages

Nothing to do.

## Docker Compose

Nothing to do. `DEACONGUARD_CLUSTER_IMAGE_REGISTRY=off` in the server's environment turns registry reads off.

## Known issues

Nothing to do.
