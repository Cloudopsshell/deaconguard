Released 2026-11-06. Everything in the release: [changelog](https://github.com/Cloudopsshell/deaconguard/blob/main/CHANGELOG.md#1320---2026-11-06). How to upgrade: [Upgrade](../../installation/upgrade.md).

## What's new

- **Live detection watches privilege, kernel modules and other processes:** a process becoming root without sudo or another setuid program, kernel modules loaded other than the system's drivers, a process taking control of another with `ptrace`, and one writing into another's memory. See [Privilege, kernel modules and other processes](../../usage/live-detection.md#privilege-kernel-modules-and-other-processes).

## Before you upgrade

Nothing to do: the database schema doesn't change.

## After you upgrade

**Upgrade the agents to 1.32.0** where live detection is on: the new rules run in the agent, so older agents keep watching programs, files and connections as before, without them. Nothing else changes: live detection stays off where it's off, and on where it's on.

## Kubernetes, install script, packages and Docker Compose

Nothing else to do: the node agent and the Compose agent already have the capabilities live detection needs.
