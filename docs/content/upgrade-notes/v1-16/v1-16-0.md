Released 2026-10-29. Everything in the release: [changelog](https://github.com/Cloudopsshell/deaconguard/blob/main/CHANGELOG.md#1160---2026-10-29). How to upgrade: [Upgrade](../../installation/upgrade.md).

## What's new

- **Finding out why the server is busy:** requests that take more than 2 seconds, and a server that keeps more than one CPU core busy for 30 seconds, are logged with what was running, on the Logs page and the server's standard output. Admins can download a 30-second CPU profile from the Logs page. See [Logs](../../usage/dashboard.md#logs).
- **A faster dashboard:** its vulnerability counts no longer slow down as scans are kept.
- **Vulnerabilities over time** shows a day's numbers in a box at the pointer, and says when nothing changed.
