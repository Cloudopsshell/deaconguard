Released 2026-10-23. Everything in the release: [changelog](https://github.com/Cloudopsshell/deaconguard/blob/main/CHANGELOG.md#190---2026-10-23). How to upgrade: [Upgrade](../../installation/upgrade.md).

## What's new

- **Agents get a port of their own, 8444, with every install method**: people use 8443, agents 8444. See [Give agents their own port](../../security/securing-the-dashboard.md#give-agents-their-own-port).
- Agents that moved to the agent port go back to the address they came from if it stops answering.
- Helm: `server.agentService`, a Service with only the agent port, for [agents outside the cluster](../../installation/kubernetes.md#agents-outside-the-cluster).
- **Enroll a machine** warns about loopback addresses, and through a port-forward suggests the cluster's agent address.
- A Kubernetes server without its admin secret waits for it instead of restarting; a server that can't start says why.

## Before you upgrade

- Allow port **8444** to the server from your machines' networks (and keep 8443 for people only). Agents keep working on 8443 until they can reach 8444.

## Kubernetes (Helm and Kustomize)

- The Service already had port 8444; nothing changes for agents inside the cluster.
- Upgrade as on [Upgrade](../../installation/upgrade.md#helm), with `--reset-then-reuse-values`.
- For agents on machines outside the cluster, set `server.agentService.enabled=true`: see [Agents outside the cluster](../../installation/kubernetes.md#agents-outside-the-cluster).

## Install script and packages

- The upgrade adds port 8444, unless you had chosen another agent port, `--agent-listen off`, or something else uses 8444. Each agent moves to it by itself once it can reach it.
- To keep one port for people and agents: `sudo deaconguard setup server --agent-listen off`.

## Docker Compose

- The Compose file already published 8444. Nothing to do.

## Known issues

- Upgrading from 1.8.x or earlier with `helm upgrade --reuse-values` fails: `nil pointer evaluating interface {}.enabled`. Use `--reset-then-reuse-values`, or upgrade straight to [1.9.2](./v1-9-2.md).
