Released 2026-11-01. Everything in the release: [changelog](https://github.com/Cloudopsshell/deaconguard/blob/main/CHANGELOG.md#1230---2026-11-01). How to upgrade: [Upgrade](../../installation/upgrade.md).

## What's new

- **Agents to upgrade are pointed out.** Once the server runs 1.23.0, the **Agents** page marks each agent older than it with **Upgrade to 1.23.0**. A note above the list gives the checks they can't run yet and the command that upgrades them. Their host pages and `deaconguard host list` say the same. See [Which agents to upgrade](../../installation/upgrade.md#which-agents-to-upgrade).
- **Agents of 1.23.0 and later** log it once when their server is newer.

## Before you upgrade

Nothing to do. There is no database change.

## Kubernetes (Helm and Kustomize)

Upgrade as on [Upgrade](../../installation/upgrade.md#helm). The chart upgrades the node agents with the server. Agents in a release of their own show **Upgrade to 1.23.0** until you upgrade that release too.

## Install script and packages

Upgrade the server first. Its **Agents** page then lists the agents still to upgrade, with the command to run on them.

## Docker Compose

Nothing else to do.

## Known issues

None.
