Released 2026-10-24. Everything in the release: [changelog](https://github.com/Cloudopsshell/deaconguard/blob/main/CHANGELOG.md#1100---2026-10-24). How to upgrade: [Upgrade](../../installation/upgrade.md).

## What's new

- **Helm:** three optional settings for `server.agentService`, the Service for [agents outside the cluster](../../installation/kubernetes.md#agents-outside-the-cluster): `externalTrafficPolicy` (`Local` lets the server see each agent's own address), `loadBalancerClass` (which load balancer implementation answers, when a cluster has several) and `nodePort` (a fixed node port instead of a random one).
- **[Reaching the agent port](../../security/agent-network.md)**, a new page: machines in the same private network, another data centre or cloud, or over the internet, and the values and firewall steps for your own data centre, Hetzner, AWS, Azure, Google Cloud, DigitalOcean, Akamai/Linode and Oracle Cloud.
- The Kubernetes page shows how to install and upgrade with [Flux, Argo CD or a pipeline](../../installation/kubernetes.md#with-flux-argo-cd-or-a-pipeline).
- The [Upgrade](../../installation/upgrade.md) page is the same for every release, and these upgrade notes have a page per release.

DeaconGuard itself, the server and the agents, is the same as 1.9.2.

## Before you upgrade

Nothing to do.

## Kubernetes (Helm and Kustomize)

- Upgrade as on [Upgrade](../../installation/upgrade.md#helm), with `--reset-then-reuse-values`. The new settings are empty unless you set them, so your Services don't change.

## Install script and packages

Nothing to do.

Nothing to do.
