Released 2026-11-05. Everything in the release: [changelog](https://github.com/Cloudopsshell/deaconguard/blob/main/CHANGELOG.md#1300---2026-11-05). How to upgrade: [Upgrade](../../installation/upgrade.md).

## What's new

- **Live detection watches network connections:** reverse shells, programs from temporary folders connecting out, and connections to crypto-mining pools' ports. Alerts name the address and port. See [Network connections](../../usage/live-detection.md#network-connections).

## Before you upgrade

**Back up: database schema 34.** Live detection alerts keep the connection's address, so 1.29 and earlier can't open the database afterwards. [Back up](../../usage/backup-and-restore.md#back-up) first.

## After you upgrade

**Upgrade the agents to 1.30.0** where live detection is on: the network rules run in the agent, so older agents keep watching programs and files as before, without them. Nothing else changes: live detection stays off where it's off, and on where it's on.

## Kubernetes, install script, packages and Docker Compose

Nothing else to do: the node agent and the Compose agent already have the capabilities live detection needs.
