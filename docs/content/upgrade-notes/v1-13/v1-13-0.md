Released 2026-10-29. Everything in the release: [changelog](https://github.com/Cloudopsshell/deaconguard/blob/main/CHANGELOG.md#1130---2026-10-29). How to upgrade: [Upgrade](../../installation/upgrade.md).

## What's new

- **Repository watches order tags by build time** on registries that don't say when a tag was pushed, such as GHCR, GitLab, Harbor or a self-hosted registry: by when each image was built, then by version, so tags named by commit come in build order. The watch dialog's preview shows when each matching tag was built. See [Watch a repository](../../usage/images.md#watch-a-repository).

## Before you upgrade

Nothing to do. Watches you already have keep the order of the tags they've seen; build times order a new watch's first check, and tags that appear at the same check.

## Kubernetes (Helm and Kustomize)

- Upgrade as on [Upgrade](../../installation/upgrade.md#helm). The chart doesn't change.
