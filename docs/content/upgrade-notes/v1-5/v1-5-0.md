Released 2026-10-19. Everything in the release: [changelog](https://github.com/Cloudopsshell/deaconguard/blob/main/CHANGELOG.md#150---2026-10-19). How to upgrade: [Upgrade](../../installation/upgrade.md).

## What's new

- **Kubernetes clusters**: `deaconguard kube scan`, and a **cluster agent** that puts a cluster on the Hosts page, scans it when it changes, and can warn on `kubectl apply` (admission warnings).
- Findings name the DISA Kubernetes STIG rules they check.

## Before you upgrade

- The database moves to schema 23 on the first start. [Back up](../../usage/backup-and-restore.md) first: an earlier release can't open it afterwards.

## Kubernetes (Helm and Kustomize)

- The chart adds the cluster agent (`cluster.enabled=true`) and admission warnings (`cluster.admission.enabled=true`): see [Kubernetes clusters](../../usage/kubernetes.md).

## Install script and packages

Nothing to do.

## Docker Compose

Nothing to do.

## Known issues

- Upgrading from 1.4.0 or earlier to the 1.5.0 to 1.9.1 charts with `helm upgrade --reuse-values` fails at `cluster.enabled`. Use `--reset-then-reuse-values`, or upgrade straight to [1.9.2](../v1-9/v1-9-2.md).
