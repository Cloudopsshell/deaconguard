Released 2026-11-05. Everything in the release: [changelog](https://github.com/Cloudopsshell/deaconguard/blob/main/CHANGELOG.md#1310---2026-11-05). How to upgrade: [Upgrade](../../installation/upgrade.md).

## What's new

- **A new server scans itself:** the first machine that enrolls, with the install script the server's own, is scanned once with the [recommended checks](../../checks.md#recommended-checks).
- **Recommended checks** are ticked in the scan dialog at first.
- Clearer first-run messages in the install script, for installs without a terminal and machines without systemd.

## Before you upgrade

Nothing to do: the database schema stays at 34.

## After you upgrade

- A server that has scanned anything before never starts a scan on its own: the first scan is only for new servers.
- The scan dialog remembers what you chose last; if you never chose, it now ticks the recommended checks instead of packages only. Schedules, `deaconguard scan` and the API keep the checks they're given.
