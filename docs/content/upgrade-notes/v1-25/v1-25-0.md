Released 2026-11-01. Everything in the release: [changelog](https://github.com/Cloudopsshell/deaconguard/blob/main/CHANGELOG.md#1250---2026-11-01). How to upgrade: [Upgrade](../../installation/upgrade.md).

## What's new

- **Web site checks.** `deaconguard web check`, `net scan --web`, and network targets on the dashboard check web sites without logging in. They look for published `.git` and `.env` files, public status and debug pages, CORS that trusts any origin, missing HTTPS redirects, and weak cookies and headers. See [Web sites](../../usage/network.md#web-sites).

## Before you upgrade

**Back up: database schema 30.** Network targets get two settings, so 1.24 and earlier can't open the database afterwards. [Back up](../../usage/backup-and-restore.md#back-up) first.

## After you upgrade

- **Existing network targets** keep scanning as before: web checks are off for them. To turn them on, open the target, click **Edit**, and tick **Check every web site found**. New targets have it on.
- **Before turning it on for sites behind a web application firewall:** the checks ask for paths such as `/.env`. Leave **Look for files and pages that should never be public** unticked if the firewall would block the server's address.
