Released 2026-10-17. Everything in the release: [changelog](https://github.com/Cloudopsshell/deaconguard/blob/main/CHANGELOG.md#100---2026-10-17). How to upgrade: [Upgrade](../../installation/upgrade.md).

## What's new

- The first stable release: server and agents, package vulnerabilities, optional checks, server audits, reports, notifications, and the install script, packages, container image, Helm chart, Compose and Kustomize files.

## Before you upgrade

- From 0.x: back up, then upgrade the server, then each agent. The database is upgraded in place, and no setting changes.

## Kubernetes (Helm and Kustomize)

Nothing to do.

## Install script and packages

- Run the install script again, on the server first.

## Docker Compose

Nothing to do.
