# DeaconGuard CLA signatures

This branch holds the record of who has signed the
[DeaconGuard Contributor License Agreement](https://github.com/Cloudopsshell/deaconguard/blob/main/CLA.md).

The [CLA workflow](https://github.com/Cloudopsshell/deaconguard/blob/main/.github/workflows/cla.yml)
adds an entry to `signatures/version1/cla.json` when a contributor signs on a pull
request. Don't edit it by hand, and don't merge this branch into `main`.
