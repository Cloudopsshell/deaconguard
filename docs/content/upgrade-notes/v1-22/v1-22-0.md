Released 2026-11-01. Everything in the release: [changelog](https://github.com/Cloudopsshell/deaconguard/blob/main/CHANGELOG.md#1220---2026-11-01). How to upgrade: [Upgrade](../../installation/upgrade.md).

## What's new

- **Host changes**, a new check, reports what changed on a machine since its previous scan: a new port open to the network, account, administrator, sudoers rule, SSH key, enabled service or scheduled job. See [Host changes](../../usage/host-changes.md).
- **Host changes notifications**, for the channels that tick them.

## Before you upgrade

Nothing to do. The check is off until you choose it.

## To use it

1. Upgrade the agents to 1.22.0: the server refuses the check for older agents and says so.
2. Add **Host changes** to your hosts' [schedule](../../usage/dashboard.md#schedules). Its first scan of each machine is the baseline; changes are reported from the second.
3. To be told about changes, tick **Host changes** on a [notification channel](../../usage/notifications.md#events).

## Kubernetes (Helm and Kustomize)

Upgrade as on [Upgrade](../../installation/upgrade.md#helm): the chart upgrades the node agents with the server. On a Kubernetes node the check records the node itself, not its pods; ports that pods publish on the node through `hostPort` or `hostNetwork` are included.
