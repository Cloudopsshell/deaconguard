Released 2026-10-22. Everything in the release: [changelog](https://github.com/Cloudopsshell/deaconguard/blob/main/CHANGELOG.md#180---2026-10-22). How to upgrade: [Upgrade](../../installation/upgrade.md).

## What's new

- **macOS**: Macs are scanned, from macOS 10.15, with a macOS baseline for audits; the agent installs on a Mac with the same command.
- **Compiled Go programs** are checked for Go's and their modules' vulnerabilities.
- **Running containers**: details for each container, stopped containers listed, and every vulnerability as a tree. The host's library check skips container storage.
- Built with Go 1.26.10, which refuses the compromised eMudhra CA keys.

## Before you upgrade

- Upgrade the server before the agents: a 1.8 agent also sends stopped containers, which a 1.7 server shows as running ones with nothing found.

## Kubernetes (Helm and Kustomize)

- The agent DaemonSet lists each node's stopped containers too. Upgrade as on [Upgrade](../../installation/upgrade.md#helm), with `--reset-then-reuse-values`.

## Install script and packages

- On a Mac, the same install command installs the agent. Servers run on Linux only.
