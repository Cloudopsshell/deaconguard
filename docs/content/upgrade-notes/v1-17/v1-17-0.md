Released 2026-10-29. Everything in the release: [changelog](https://github.com/Cloudopsshell/deaconguard/blob/main/CHANGELOG.md#1170---2026-10-29). How to upgrade: [Upgrade](../../installation/upgrade.md).

## What's new

- **Faster scans of Ubuntu, Debian, Red Hat and the other large feeds:** each feed is read once and kept for the scans that follow, so a second scan of an Ubuntu 24.04 machine or image no longer spends half a minute of CPU reading Canonical's feed. See [Parsed feeds](../../supported-distributions.md#parsed-feeds).
- **An access log**, off by default: a line on standard output for each request. See [Logs](../../usage/dashboard.md#logs).
- Each server line on standard output starts with its level, and an Amazon ECR key that may not list repositories gets a clearer message.

## Before you upgrade

- The server now keeps parsed feeds in memory, up to about 400 MB. A server with 1 GB or more needs nothing. On a smaller one, or a container with a lower memory limit, lower it with `DEACONGUARD_FEED_CACHE_MB` (or `0` to turn it off).

## Kubernetes (Helm and Kustomize)

- Upgrade as on [Upgrade](../../installation/upgrade.md#helm). Two new values: `server.feedCacheMB` (400) and `server.accessLog` (off). Keep `server.feedCacheMB` well under `server.resources.limits.memory` (1Gi by default); to keep two Ubuntu releases, set it to 700.

## Install script and packages

Nothing to do.

## Docker Compose

Nothing to do. To turn on the access log, add `DEACONGUARD_ACCESS_LOG: "1"` to the server's `environment`.

## Known issues

Nothing to do.
