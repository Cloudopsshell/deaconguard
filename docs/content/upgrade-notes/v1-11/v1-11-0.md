Released 2026-10-25. Everything in the release: [changelog](https://github.com/Cloudopsshell/deaconguard/blob/main/CHANGELOG.md#1110---2026-10-25). How to upgrade: [Upgrade](../../installation/upgrade.md).

## What's new

- **Helm, with Traefik** (such as on k3s): `server.ingress.traefik.enabled` creates what Traefik needs to reach the dashboard, and `.allowSourceRanges` an IP allow list for it; `server.agentRoute` brings agents outside the cluster in through Traefik on port 443, with TLS passed through. See [With Traefik](../../installation/kubernetes.md#with-traefik).
- Updated dashboard icons and the release workflow's signing tools.

DeaconGuard itself, the server and the agents, works as in 1.10.0.

## Before you upgrade

Nothing to do.

## Kubernetes (Helm and Kustomize)

- Upgrade as on [Upgrade](../../installation/upgrade.md#helm), with `--reset-then-reuse-values`. The new settings are off unless you set them, so nothing changes.
- If you set up Traefik by hand (a `ServersTransport`, an `ipAllowList` middleware, and Traefik annotations on the Service and Ingress), you can replace them with `server.ingress.traefik`: turn it on, remove your Service annotations and your `router.middlewares` annotation for the allow list, upgrade, then delete your own `ServersTransport` and `Middleware`.
