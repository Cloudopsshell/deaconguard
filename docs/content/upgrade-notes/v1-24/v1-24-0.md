Released 2026-11-01. Everything in the release: [changelog](https://github.com/Cloudopsshell/deaconguard/blob/main/CHANGELOG.md#1240---2026-11-01). How to upgrade: [Upgrade](../../installation/upgrade.md).

## What's new

- **DISA STIG rules on the Linux baseline.** On Ubuntu 22.04 and 24.04 and RHEL 8 and 9 (and Rocky Linux and AlmaLinux), each audit control names the STIG rules it checks. A control says so when the STIG asks for more than it checks. The **Compliance** card and reports have a **DISA STIG** framework. See [DISA STIG](../../usage/compliance.md#disa-stig).

## Before you upgrade

Nothing to do. There is no database change.

## After you upgrade

- **Agents:** the rules are added on the server, so agents need no upgrade. Audits from before the upgrade show them too.
- **Reports:** CSV and Excel reports get a **DISA STIG** column, the last one. Scripts that read the columns by position are unaffected; scripts that check the column count need updating.

## Kubernetes (Helm and Kustomize)

Nothing else to do.

Nothing else to do.

## Docker Compose

Nothing else to do.

None.
