Released 2026-11-02. Everything in the release: [changelog](https://github.com/Cloudopsshell/deaconguard/blob/main/CHANGELOG.md#1290---2026-11-02). How to upgrade: [Upgrade](../../installation/upgrade.md).

## What's new

- **A cluster's nodes' findings, combined:** the cluster's page has **Vulnerabilities**, **Malware** and **File integrity** tabs, each finding once, with the nodes it's on. See [The cluster's page](../../usage/kubernetes.md#the-clusters-page).
- **Counted once:** the dashboard, its trends, fix deadlines and the Hosts list count a cluster's nodes' vulnerabilities once, as the cluster's.
- **Live detection** on a machine that couldn't run it tries again every 5 minutes, instead of every hour.

## Before you upgrade

Nothing to do: the database schema stays at 33.

## After you upgrade

The dashboard's numbers go down for clusters whose nodes share vulnerabilities: a package on three nodes counted three times, and now counts once. Nothing was fixed or hidden; each node's own page still lists all of its findings.

Trends count a cluster once from its first node scan after the upgrade. Days before it count its nodes one by one, as they did, so a cluster's line may step down on that day.

## Kubernetes, install script, packages and Docker Compose

Nothing else to do. Agents need no upgrade for the combined findings; upgrade them for the quicker live detection retry.
