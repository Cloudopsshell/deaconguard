Released 2026-11-15. Everything in the release: [changelog](https://github.com/Cloudopsshell/deaconguard/blob/main/CHANGELOG.md#1331---2026-11-15). How to upgrade: [Upgrade](../../installation/upgrade.md).

## What's new

- **New contact addresses:** security reports go to security@deaconguard.io, and the packages and Helm chart name hello@deaconguard.io as maintainer. See [Reporting a vulnerability](../../security/reporting.md).
- **Updated libraries:** the SQLite driver, compression and system libraries, and the dashboard's build tools. Nothing behaves differently.

## Before you upgrade

Nothing to do. The database stays at schema 35, so a 1.33.0 server can still open it.

## After you upgrade

Nothing to do. Agents on 1.33.0 work with a 1.33.1 server and need no upgrade.

## Kubernetes, install script, packages and Docker Compose

Nothing else to do.
