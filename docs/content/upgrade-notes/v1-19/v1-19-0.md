Released 2026-10-31. Everything in the release: [changelog](https://github.com/Cloudopsshell/deaconguard/blob/main/CHANGELOG.md#1190---2026-10-31). How to upgrade: [Upgrade](../../installation/upgrade.md).

## What's new

- **Malware in containers:** the malware and antivirus checks also scan what each running container wrote since it started: its writable layer and its Kubernetes emptyDir volumes. Findings name the container, and malware notifications list the containers. See [Malware in containers](../../usage/containers.md#malware-in-containers).
- **Lighter antivirus scans:** ClamAV loads its signatures once for the machine and all its containers, and the YARA rules are compiled once per scan instead of once per folder. Both run at the lowest CPU and disk priority.
- The [Kubernetes](../../installation/kubernetes.md) page sets out the server, the node agent and the cluster agent, and who checks what in your pods.

## Before you upgrade

- Container malware scanning happens on the **agent**, so upgrade the agents to get it; agents before 1.19.0 scan the machine as before. The server needs no change to its database.
- The first scans after the upgrade may report malware in containers that earlier scans couldn't see. That isn't new malware: it was there before.

## Kubernetes (Helm and Kustomize)

- Upgrade as on [Upgrade](../../installation/upgrade.md#helm). The chart's values don't change.
- The node agent DaemonSet scans its pods' containers with the node's own `clamscan` and `yr`: a node without them reports the antivirus checks as skipped, as before.

## Install script and packages

Nothing to do: running the install script again upgrades the agent.
