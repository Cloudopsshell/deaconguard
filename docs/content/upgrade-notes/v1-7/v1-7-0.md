Released 2026-10-20. Everything in the release: [changelog](https://github.com/Cloudopsshell/deaconguard/blob/main/CHANGELOG.md#170---2026-10-20). How to upgrade: [Upgrade](../../installation/upgrade.md).

## What's new

- **Passkeys**, which count as two-step sign-in, and **single sign-on** with OpenID Connect providers such as Entra ID, Google, Okta or Keycloak.

## Before you upgrade

- The database moves to schema 26 on the first start. [Back up](../../usage/backup-and-restore.md) first: an earlier release can't open it afterwards.
- Passkeys need the dashboard on a name with a trusted certificate.
