Released 2026-10-29. Everything in the release: [changelog](https://github.com/Cloudopsshell/deaconguard/blob/main/CHANGELOG.md#1140---2026-10-29). How to upgrade: [Upgrade](../../installation/upgrade.md).

## What's new

- **Docker Hub and GHCR say when each tag was pushed:** repository watches pick the most recently pushed tags there, as on Amazon ECR, and browsing a Docker Hub or GHCR login lists its repositories. See [Browse a registry](../../usage/images.md#browse-a-registry).

## Before you upgrade

- If the server's outbound traffic is limited, allow `hub.docker.com` (for Docker Hub) and `api.github.com` (for GHCR) on port 443. Without them, tags are listed as in 1.13.0. See [Requirements](../../installation/requirements.md#network).
- For GHCR push times and package lists, the GHCR login's token must be a classic one with `read:packages`; GitHub's API refuses fine-grained tokens. A login that works for scanning keeps working either way.

## Kubernetes (Helm and Kustomize)

- Upgrade as on [Upgrade](../../installation/upgrade.md#helm). The chart doesn't change.
