Released 2026-10-31. Everything in the release: [changelog](https://github.com/Cloudopsshell/deaconguard/blob/main/CHANGELOG.md#1203---2026-10-31). How to upgrade: [Upgrade](../../installation/upgrade.md).

## What's fixed

- **The server no longer runs out of memory checking images on several Ubuntu releases**, as a cluster scan can: in Kubernetes, with the chart's 1 GiB limit, it was stopped (`OOMKilled`) and restarted, and the scan failed. The server now keeps its memory under the limit it runs under, and reads one large feed at a time. See [Parsed feeds](../../supported-distributions.md#parsed-feeds).

## Before you upgrade

Nothing to do.

## Kubernetes (Helm and Kustomize)

- Upgrade as on [Upgrade](../../installation/upgrade.md#helm).
- If you raised `server.resources.limits.memory` to work around the restarts, you can set it back to 1Gi.
- A scan that failed when the server restarted is marked failed; run it again.

## Install script and packages

Nothing to do. The server isn't limited by default; if you set `MemoryMax` on its systemd unit, it now keeps under it.

## Docker Compose

Nothing to do. With a memory limit on the server's container (`mem_limit` or `deploy.resources.limits.memory`), it now keeps under it.

## Known issues

Nothing to do.
