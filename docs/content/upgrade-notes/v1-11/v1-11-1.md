Released 2026-10-25. Everything in the release: [changelog](https://github.com/Cloudopsshell/deaconguard/blob/main/CHANGELOG.md#1111---2026-10-25). How to upgrade: [Upgrade](../../installation/upgrade.md).

## What's new

- **Exploit data on cloud servers:** when CISA's site refuses the Known Exploited Vulnerabilities download, as it does for some cloud providers' addresses (HTTP 403), the server takes the same catalog from CISA's copy on GitHub. Findings get their "known exploited" marks again, and the host page no longer shows **CISA KEV: unavailable**.

## Before you upgrade

- If the server's outbound traffic is limited, allow `raw.githubusercontent.com` on port 443, next to `www.cisa.gov`. See [Requirements](../../installation/requirements.md#network).

## Kubernetes (Helm and Kustomize)

- Upgrade as on [Upgrade](../../installation/upgrade.md#helm). The chart doesn't change.
