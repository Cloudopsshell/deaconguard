## What's new

- **Images in registries**: `deaconguard image scan`, and an **Images** page that scans registry images, watches tags for new builds and keeps registry logins, Amazon ECR included.

## Before you upgrade

- The database moves to schema 22 on the first start. [Back up](../../usage/backup-and-restore.md) first: an earlier release can't open it afterwards.
