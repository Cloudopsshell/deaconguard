Released 2026-10-18. Everything in the release: [changelog](https://github.com/Cloudopsshell/deaconguard/blob/main/CHANGELOG.md#110---2026-10-18). How to upgrade: [Upgrade](../../installation/upgrade.md).

## What's new

- **Application libraries** checked against OSV, and an **SBOM** for every scan.
- The documentation moved to the repository and is published from each release.

## Before you upgrade

- Upgrade the server first, then the agents: agents before 1.1.0 are refused the library check.
- The server needs HTTPS access to `api.osv.dev` for the library check.
