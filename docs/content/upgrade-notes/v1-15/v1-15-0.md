Released 2026-10-29. Everything in the release: [changelog](https://github.com/Cloudopsshell/deaconguard/blob/main/CHANGELOG.md#1150---2026-10-29). How to upgrade: [Upgrade](../../installation/upgrade.md).

## What's new

- **Push times from more registries:** repository watches pick the most recently pushed tags on Google Artifact Registry and gcr.io, Azure Container Registry, Quay, Harbor and GitLab too, and browsing a Harbor login lists its repositories. See [Watch a repository](../../usage/images.md#watch-a-repository).

## Before you upgrade

- If the server's outbound traffic is limited and you watch repositories on registry.gitlab.com, allow `gitlab.com` on port 443; for a self-hosted GitLab, its own host. Without it, tags are listed as in 1.14.0. See [Requirements](../../installation/requirements.md#network).
- For push times of private repositories, some registries need a different login than for scanning: an OAuth token as `$oauthtoken` on Quay, and an access token with `read_api` on GitLab. See [Registries and logins](../../usage/images.md#registries-and-logins). Logins that work for scanning keep working either way.
